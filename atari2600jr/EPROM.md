🧪 1. Atari 2600 “Test Cart” (Official Atari Service Diagnostic)

This is the closest thing to a real service ROM Atari ever produced.
What it tests:

    Color bars

    Audio tones

    Joystick directions

    Paddle range

    Switch inputs

    Basic TIA output

Notes:

    Originally used by Atari service centers

    Exists as a ROM dump

    Works on any standard 2600 hardware

    Very small (2 KB)

If you want a “proper” diagnostic cart, this is the one.
🧪 2. Atari Field Service Diagnostic (Another Atari‑authored ROM)

A slightly different version used by field techs.
Features:

    Color calibration

    Audio test

    Input test

    TIA pattern tests

It’s less common but still available as a ROM image.
🧪 3. “Stella Test Suite” (Homebrew Diagnostic ROMs)

These are modern, community‑made test ROMs designed for emulator accuracy — but they run perfectly on real hardware.
Includes:

    TIA timing tests

    Sprite positioning tests

    Collision detection tests

    Color accuracy patterns

    Overscan/blanking tests

These are incredibly useful if you want to verify your console’s video output or compare RF vs composite later.
🧪 4. “TIA Color Test” / “Color Bars” ROMs

Simple but useful:

    Full‑screen color bars

    NTSC color phase reference

    Great for tuning RF, adjusting TV color, or checking for TIA drift

🧪 5. Joystick/Paddle Test ROMs (Homebrew)

There are several tiny ROMs that:

    Show joystick direction visually

    Display paddle position as a bar

    Test button presses

    Test both ports independently

These are great if you’re refurbishing controllers.
🔧 Burning These to a Cartridge

Most diagnostic ROMs are:

    2 KB or 4 KB

    Standard 2600 addressing

    No bankswitching required

So you can burn them to:

    2732 EPROM (4 KB)

    2764 EPROM (8 KB, padded)

    Or use a multi‑ROM board and switch between tests
