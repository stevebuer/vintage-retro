# Atari 2600 Jr.

<img src="2600jr.jpg">

Purchased at Dreamquest Games Poulsbo

## Specs

* MOS 6507 @ 1.19 Mhz
* 128 bytes RAM in 6532 RIOT chip
* ROM 4k (more with bank switching)

## Initial Testing

* Works fine with Roku TV antenna input
* RF cable was noisy, switched for better RCA but not 75 ohm.
* Joystick as not that good
